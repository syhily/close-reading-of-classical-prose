# OCR 校对与 Markdown 规范

## 一、多模式交叉校对

本书 PDF 共 455 页，超出 MinerU flash-extract 的 10MB / 20 页限制，统一使用
`mineru-open-api extract`（需在 https://mineru.net/apiManage/token 申请 token，
`mineru-open-api auth` 配置）。

`make ocr` 会跑两种模式：

| 模式 | 特点 | 用途 |
|------|------|------|
| `pipeline` | 无幻觉，逐字可靠 | **校对基准** |
| `vlm` | 复杂版式（脚注、引文混排）精度更高，偶有幻觉 | 交叉比对 |

校对方法：

1. 以 `ocr/pipeline/` 结果为底稿；
2. 用 diff 工具（如 `diff -u`、`code --diff`）对照 `ocr/vlm/` 结果，
   两处不一致的地方即为疑似识别错误，**对照原 PDF 页面**定夺；
3. 脚注混排、选文缩进等版式复杂处，以 vlm 结果为参照检查 pipeline 底稿；
4. 若需对个别疑难页第三次识别，可用 `--pages N-M` 单页重跑某一模式。

对照原书页面用 Ghostscript 渲染（存 `ocr/pages-probe/`，不入库）：

```sh
gs -dNOPAUSE -dBATCH -sDEVICE=jpeg -r150 -dFirstPage=N -dLastPage=M \
   -sOutputFile=ocr/pages-probe/page-%03d.jpg source/孙绍振古典散文解读全编.pdf
```

注意：MinerU 两种模式都可能整条漏收页底小字脚注，校时每页页底都要扫一眼原书；
原书自身的误植照录不擅改，加 `<!-- 疑：原书作「x」 -->` 留待复核。

## 二、文件切分

校对后的正文放入 `manuscript/`，文件名以两位序号开头保证顺序：

```
manuscript/00-frontmatter.md     # 电子版说明与免责声明（不进目录）
manuscript/01-preface.md         # 序
manuscript/02-introduction.md    # 导读：古代散文的解读观念和方法
manuscript/10-xxx.md             # 正文按原书页序分组，每组若干篇
...
```

pandoc 按文件名排序合并，构建时自动生成目录；`--split-level=2` 把每个 `##` 篇
拆成独立 xhtml 文件（即硬分页），脚注按 pandoc 默认行为收集在各篇文件末尾。

构建用到的过滤器：

- `scripts/newpage.lua`：硬换页标记。正文里独占一行的 `\newpage` 转换为
  空的 `.unlisted` 二级标题，借助 `--split-level=2` 的文件拆分实现换页，
  不依赖 CSS `page-break`（部分阅读器不支持）；空标题不渲染、不进目录。
  注意 `\newpage` 是 LaTeX 命令，会被 `raw_tex` 解析为 `RawBlock`，
  过滤器须处理 `RawBlock` 而非 `Para`（EPUB 输出会静默丢弃前者）。
- `scripts/ascii-heading-ids.lua`：标题锚点改写为 ASCII id（`sec-N`），
  保证各阅读器里目录链接可跳转。
- `scripts/poem-stanzas.lua`：行块里的空行（裸 `|`）视为诗节分界，拆成多个
  行块形成分段；EPUB 输出时行块整体序列化成单行原始 HTML
  （`<br />` 后不留换行），避免 Boox 等阅读器把行首空白渲染成缩进。
- `scripts/pangu.lua`：盘古之白——在中文字符与西文/数字相邻处插入窄空格
  （U+2009）。阅读器对 `text-autospace` 等 CSS 属性支持极差，插入真实
  字符是唯一可靠方案；已有空格或标点隔开的边界不动。
- `scripts/poem-title.lua`、`scripts/xuanwen-title.lua`、
  `scripts/chapter-titlepage.lua`：诗块/长选文/章扉页标题处理，移植自
  close-reading-of-classical-poetry；本书为散文解读，一般不使用 `.poem`
  居中诗块与「第X章」章扉页，保留过滤器以维持工具链一致。

有序列表使用 pandoc 原生 `<ol start="N">` 输出，不做额外改写。

## 三、Markdown 书写约定

### 标题

层级与原书目录一致（EPUB 目录深度为 3 级）。本书为扁平结构（无章节），
原书目录中的每一条目——序、导读、各篇解读——一律用一级标题：

- `#` 序、导读、各篇解读标题（居中黑体大字，独立成页；各篇保持原书
  「《篇名》：主题」格式，如「《曹刿论战》：只有对话的战争叙事」）
- `####` 及更深：篇内小节标题——**不进目录**。本书篇内小节标题居中黑体
  （如「一、八个层次的美」，或裸序号「一」），与诗词书靠左小标题不同，
  由 epub.css 的 h4 规则实现（本书特化，勿回改）

一句话：凡原书目录里能看到的条目，一律 `#`；目录里没有的篇内小节标题一律 `####` 起。

电子版说明与免责声明（`00-frontmatter.md`）标题加 `{.unlisted}`，
使其**不进**电子书目录——原书纸质目录同样不列扉页与版权页。

### 脚注

统一使用 pandoc **行内脚注**，脚注内容直接跟在正文之后：

```markdown
正文文字^[这是脚注内容。]继续正文。
```

不要用 `[^1]` 编号式脚注——OCR 合并多页内容时编号极易错位，
行内脚注没有编号，不存在漂移问题。

### 选文（作品原文引用）

原书版式：选文一律**楷体缩进**，无边框。分三种写法：

按段落排的散文选文用块引用：

```markdown
> 十年春，齐师伐我。公将战，曹刿请见。
```

需要逐行换行、但换行**不是分段**的选文（如骈句、韵语），
用块引用内嵌行块（`> | `）：行块保证逐行换行，外层块引用提供选文的楷体与缩进：

```markdown
> | 惟江上之清风，与山间之明月，
> | 耳得之而为声，目遇之而成色。
```

文中引用的诗句用 pandoc **行块**（行首 `| `），整体左缩进：

```markdown
| 落霞与孤鹜齐飞，秋水共长天一色。
```

长选文（含多个段落、标题）用 fenced div：

```markdown
::: {.xuanwen}
**《陋室铭》刘禹锡**

山不在高，有仙则名……
:::
```

### 着重号

原书在字下**加点**表示着重（不是加粗）。用 pandoc Bracketed Span：

```markdown
……[审美]{.zhuozhong}价值与实用理性……
```

渲染分两层：支持 `text-emphasis` 的阅读器显示标准的字下圆点；不支持的
用 `::after` 在文字下方铺「・」模拟。着重号**不改变字体**（随上下文，
楷体选文里的着重词仍是楷体），只靠字下点表示强调。
**只标短词**（几个字），模拟点按宽度截断，不适合整句或跨行长串。

### 落款

题跋、书信等末尾的署名右对齐：

```markdown
[——读者]{.qianming}
```

### 字体分工（由 assets/epub.css 实现，跨平台回退到各系统字体）

| 内容 | 字体 | Markdown 写法 |
|------|------|---------------|
| 正文 | 阅读器默认字体（CSS 不指定） | 普通段落 |
| 序、导读、各篇标题（居中） | 黑体 | `# …` |
| 篇内小节标题（居中） | 黑体 | `#### …` |
| 选文、引文、诗句 | 楷体 | `> `、`::: {.xuanwen}`、行块 `| ` |
| 着重号 | 字下加点（不改字体，随上下文） | `[…]{.zhuozhong}` |
| 扉页信息、题辞、出版说明 | 仿宋 | `::: {.fangsong}` |
| 落款署名 | 右对齐（随正文默认字体） | `[…]{.qianming}` |
| 整页扫描图版（插页） | 居中缩放至一页内（插图全局规则），图注不显示（说明文字留在 alt 属性） | `\newpage` 后 `![说明](assets/…)` |

CSS 已在 Clearview 与 Boox Note 上调试好兼容性，**不要贸然改动**；
能用 Markdown / Lua 过滤器解决的排版问题，不动 CSS。

### 其他

- 强制换页：独占一行写 `\newpage`（`scripts/newpage.lua` 转为文件级硬分页，
  见「二、文件切分」），不要用 CSS `page-break`（部分阅读器不支持）；
- 行内强调用 `*…*`（排楷体，中文不倾斜）；`**…**` 排黑体；
- 行块的竖线必须是 ASCII `| `，全角 `｜` 不会被 pandoc 解析（OCR 结果容易混入）；
- 书名号《》保留原样，不要改成斜体；
- 页眉、页码、书脊文字等杂质一律删除；
- 拿不准的字，在行间加 HTML 注释 `<!-- 疑：原书作「x」 -->` 留待复核。

## 四、完稿统一

- 正文半角标点转全角（`?`→`？` 等），跳过脚注/HTML 注释/URL/西文语境：
  `python3 scripts/normalize-punct.py manuscript/*.md`
- 脚注里原书「同①」「同①84.」等简式引用，一律展开为完整文献（渲染该页页底找回 ① 的全文）
- 连续空行折叠为一；页眉页码、圈码、图片引用、编号式脚注、全角竖线均不得残留
